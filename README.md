# Escapen't Homepage

This is the official **Homepage for Escapen't**, a thrilling escape room game! The webpage is designed using **HTML**, **CSS**, and a bit of **JavaScript** to showcase the game and introduce the development team. It provides information about the game’s storyline, features, and the team behind its creation, with a clean and interactive user experience.

## 🚀 Demo

Check out the live version of the Escapen't homepage [here](https://tezk1993.github.io/KaffeKlubben-Games-Website/).

## Features

- **Game Overview**: Highlight the key features and storyline of Escapen't, giving visitors an enticing glimpse of the gameplay.
- **Team Section**: Introduce the development team, with profiles for each team member, including their role and contributions.
- **Responsive Design**: Optimized for a seamless browsing experience on desktops, tablets, and mobile devices.
- **Interactive Elements**: Simple animations and JavaScript interactions to enhance user engagement.
- **Clean UI**: A polished and minimal design to keep the focus on the content and visuals.

## 🛠️ Technologies Used

- **HTML**: For structuring the content and layout of the page.
- **CSS**: Used for designing a visually appealing and responsive user interface.
- **JavaScript**: A bit of JavaScript for adding simple interactivity and animations.

## 📂 Sections

- **Welcome Section**: A brief introduction to the game with eye-catching visuals.
- **About the Game**: Detailed overview of the Escapen't game, including its storyline and unique features.
- **Meet the Team**: Profiles of the team members, including their roles and social media links.
- **Screenshots and Trailers**: A gallery showcasing screenshots and trailers to give users a preview of the game.
- **Contact Information**: Links to social media, email, and any other relevant communication channels.
